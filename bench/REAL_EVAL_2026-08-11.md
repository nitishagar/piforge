## Throughput finding (material, separate from the capability verdict)

Cactus's `decoder_full_context` execution strategy **recomputes the full context
on every prefill** (no incremental KV cache across turns). Combined with the Pi
5 CPU, each chat completion took ~1.3–4.5 min (growing as turn history grows):
18 completions for 7 cases in ~35 min wall-clock. Extrapolated to the full
40-case set at max_turns=12, a single eval run would take **~8+ hours**. This
is a cactus-side constraint (the bundle's execution strategy), not a piforge
issue. Any follow-up real run should either (a) use a cactus bundle built with
dynamic-kv caching (`--cache-style dynamic-kv`) to avoid full-recompute, or
(b) accept the multi-hour budget.
